Empfehlungen für Einsteiger
-----------------------------

1. **Virtuelle Umgebung** (isolierte Python-Umgebung) erstellen und aktivieren:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. **Abhängigkeiten installieren** (benötigte Pakete):
   ```bash
   pip install -r requirements.txt
   ```
3. **Tests starten** (Prüfung):
   ```bash
   pytest -q
   ```
4. **Programm ausführen**:
   ```bash
   python app.py
   ```
