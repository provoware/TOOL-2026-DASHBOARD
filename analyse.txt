Empfehlungen für Einsteiger
-----------------------------

1. **Virtuelle Umgebung** (isolierte Python-Umgebung) erstellen und aktivieren:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. **Abhängigkeiten installieren** (benötigte Pakete):
   ```bash
   pip install -r requirements.txt
   ```
3. **Tests starten** (Prüfung):
   ```bash
   pytest -q
   ```
4. **Programm ausführen**:
   ```bash
   python app.py
   ```

Weiterführende Tipps
--------------------

* Die erzeugte **Logdatei** findest du im Ordner `logs` unter dem Namen `modultool.log`. Dort steht in der ersten Zeile "Logger initialisiert".
* Bei Fehlermeldungen hilft oft ein Blick in diese Datei. Sie enthält Protokolle ("Logs") aller Aktionen.
* Möchtest du die Testergebnisse zusätzlich speichern, nutze:
  ```bash
  pytest -q | tee last_test.log
  ```
  Der Befehl `tee` kopiert die Ausgabe in eine Datei und zeigt sie gleichzeitig im Terminal an.
* Alle wichtigen Pfade sind nun in `modultool/config.py` gesammelt. Dort findest du auch die aktuelle **Versionsnummer** (`APP_VERSION`).
* Prüfe die Dummy-Daten im Ordner `data/defaults` bei Bedarf so:
  ```bash
  cat data/defaults/genres.json
  ```
  Damit siehst du, welche Beispielgenres hinterlegt sind.

* Starte den Selfcheck manuell so:
  ```bash
  python -m modultool.selfcheck
  ```
  Das Skript legt fehlende Dateien an und schreibt eine Meldung ins Log.
